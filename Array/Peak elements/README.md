# Peak element
Given an array `arr[]` where no two adjacent elements are same, find the index of a peak element. An element is considered to be a peak if it is greater than its adjacent elements (if they exist). If there are multiple peak elements, return index of any one of them. The output will be "_true_" if the index returned by your function is correct; otherwise, it will be "_false_".
## Prerequisite
```java
import java.util.Scanner;
```
### Example
```
Input  : [1, 2, 4, 5, 7, 8, 3]
Output : true
```
![](https://img.shields.io/badge/Note-red) <br>
Consider the element before the first element and the element after the last element to be negative infinity.
